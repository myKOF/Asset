# 羊皮紙序章｜第五鏡荒漠終章

獨立第五鏡長 16 秒，1920 × 1080，30 fps，第一格直接進入分層演出，風沙、地面敵人和飛行敵人同步出現，尾段延長 3 秒，場景與劍光在第 14.9 秒一起淡出。此成片只含第五鏡。

- 遠方天空左移 34 像素，建築左移 72 像素，中景地表固定，近地與人物右移 70 像素。數值以 1672 × 941 的原畫座標表示。以四個深度區域各自位移，交界用柔邊深度圖校正，同一位置只取一次底圖像素。
- 角色、聖劍和兩段破布從第四鏡原畫取樣。肩帶及腰布的固定端跟著盔甲，布端以獨立網格由右往左拉伸和翻動。ImageGen 補出荒漠乾淨底板，提示詞在 PROMPT.md。
- 聖劍在第 3 秒點亮。劍柄、護手與劍身多處向外放射白色光束，光束繞各自的發光位置以每秒 6 度順時針旋轉，並和光暈一同逐漸擴大。光層跟隨近景人物，約第 10.45 秒達到明亮高峰，片尾維持光束轉動，整個畫面和劍光一同淡至黑幕。風沙音效延長 3 秒並跟隨畫面收束，配樂以固定增益沿原曲接續。

- 新增 24 個地面敵人和 10 個飛行敵人，沿用第一鏡的惡魔圖集。三種飛行敵人以翼根、翼尖和翅膀前後緣分段變形，每個拍翼週期有 16 格。金色日光、煙塵、飛砂和碎石各自合成。音效以本地程序合成，沿用 Desert Ascendant 的配樂時間點。

以 node build-score.cjs 產生音軌，再以 node render-finale.cjs 重製 MP4。使用 --stills 可輸出檢視畫格。可拖曳預覽需要 WebGL，輸出需要本機 Windows Edge 和 FFmpeg。以素材庫的序章目錄為本機 HTTP 根目錄，開啟 extended-shot-five/index.html 可拖曳。渲染預設輸出至系統暫存的 idle-rpg-shot-five，可用 PARCHMENT_REVIEW_DIR 指定輸出目錄。圖集、原畫與配樂沿用素材庫內既有來源。
